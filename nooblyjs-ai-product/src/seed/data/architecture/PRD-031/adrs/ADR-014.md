## Context

The slot list must load in under 300 ms at p95 during the 18:00 peak (PRD-031 goals); today it takes 1.8 s.

## Decision

Cache slot availability per store in Redis with a 30-second TTL, refreshed on slot.released.

## Consequences

A new dependency to run (Redis). Availability can be up to 30 seconds stale; holds still check Postgres.
