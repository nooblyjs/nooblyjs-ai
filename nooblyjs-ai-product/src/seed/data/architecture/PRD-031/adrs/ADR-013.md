## Context

A hold must return to the pool within 5 seconds of expiring (PRD-031 acceptance criteria).

## Decision

The Slot API publishes slot.released on the existing Kafka event bus when a hold expires.

## Consequences

No polling load on Postgres. Consumers must be idempotent.
