# Tutorial Format Example

This shows what you'll receive when you use the `/project-tutorial` skill.

---

## 🎓 Learning: [Project Name]

### Introduction

**What You'll Learn**
- The purpose and role of this project in the larger system
- Its core functionality and responsibilities  
- How it connects to other projects
- The main technologies and patterns it uses

**Why It Matters**
- Understanding this project helps you [specific benefit]
- It's essential for working on [related areas]
- Prerequisites: familiarity with [related projects or concepts]

---

### Core Learning

#### Purpose & Overview
A clear, concise explanation of:
- What the project does
- Who uses it (internal/external)
- When and why it's used
- How it fits in the larger architecture

#### Architecture
- High-level structure (diagram if complex)
- Main directories and their purposes
- How code is organized

#### Key Components
For each major component:
- **Name**: What it does
- **Responsibility**: Its specific role
- **Interfaces**: How it's used
- **Key Files**: Where the code lives

#### How It Works
- Typical workflow/user journey
- Data flow through the system
- Key decision points
- Error handling approach

#### Key Technologies
- Framework and libraries
- Build tools and bundlers
- Testing approach
- Deployment mechanism

#### Dependencies
- Other internal projects it depends on
- External services it connects to
- APIs it provides or consumes

---

### Summary

**Main Takeaways**
- Key learning #1
- Key learning #2  
- Key learning #3

**How It Connects**
- Works with [project X] to achieve [goal]
- Depends on [project Y] for [capability]
- Provides [service] to [project Z]

**Next Steps**
- To understand [related topic], explore [related project]
- To start contributing, begin with [specific area]
- For deeper knowledge, look at [specific file/module]

---

## Continuing Your Learning

After the initial tutorial, you can:

- Ask specific questions: *"How does the authentication flow work?"*
- Request code walkthroughs: *"Show me how component X is implemented"*
- Compare projects: *"How does this differ from nooblyjs-ai-desktop?"*
- Deep dives: *"Explain the caching strategy in detail"*

**Example Follow-ups:**
```
Tell me more about the component system
How do I add a new feature to this?
What tests should I write?
Where's the best place to start making changes?
```
