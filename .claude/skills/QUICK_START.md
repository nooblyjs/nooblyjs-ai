# Quick Start: Project Tutorial Skill

## 🚀 Get Started in 30 Seconds

### Basic Usage

Type this in your Claude Code prompt:

```
/project-tutorial nooblyjs-ai-design
```

Claude will analyze the project and generate a complete tutorial following the format:
- **Introduction** - What you're about to learn
- **Core Learning** - Architecture, components, how it works
- **Summary** - Key takeaways and next steps

### Common Commands

**Learn about a specific project:**
```
/project-tutorial nooblyjs-ai-host
/project-tutorial nooblyjs-ai-harness
/project-tutorial nooblyjs-ai-factory
```

**Get a high-level overview:**
```
/project-tutorial all
```

**Get detailed code examples:**
```
/project-tutorial nooblyjs-ai-design --detailed
```

**See architecture diagrams:**
```
/project-tutorial nooblyjs-ai-host --mermaid
```

**Compare two projects:**
```
/project-tutorial --compare nooblyjs-ai-host nooblyjs-ai-desktop
```

**Save as a document:**
```
/project-tutorial nooblyjs-ai-security --save
```

## 📚 Recommended Learning Path

1. **Start here**: `/project-tutorial nooblyjs-ai-product`
   - Understand what the application does

2. **Then explore**: `/project-tutorial nooblyjs-ai-host`
   - See the main application architecture

3. **Deep dive into**: `/project-tutorial nooblyjs-ai-design`
   - Learn about UI/UX components

4. **Understand the infrastructure**: `/project-tutorial nooblyjs-ai-infrastructure`
   - See how it's deployed and hosted

5. **Follow with specifics**: Pick any other project that interests you

## 💡 Pro Tips

- **Ask follow-up questions** after each tutorial to dive deeper
